# הספרייה שלי — גרסה אישית

הבקשה: להתאים את מפרט הספרייה המשפחתית למשתמש יחיד ולהעלות את העבודה לריפוזיטורי GitHub שסופק, `itoosh-45/parttry2`.

## התאמה למשתמש יחיד

בעלים אחד לכל העותקים, שם הניתן לעריכה בהגדרות, דירוג אישי אחד לכל כותר ומעקב קריאה אישי. אין רשימת בני משפחה, ממוצע משפחתי או שיוך למשתמשים שונים. מיקומים מוגדרים בהגדרות; המיקום הראשוני הוא הבית שלי.

## מסכים וזרימות

בית עם חיפוש והוספה מהירה; ספרייה עם סינון, מיון, כריכות ורשימה; פרטי כותר עם עותקים, דירוג והיסטוריה; הוספה ידנית, חיפוש בקטלוג, צילום וברקוד; השאלות פעילות והיסטוריה; קריאה אישית; רשימת קנייה; התראות; הגדרות וגיבוי.

כותר חדש נוצר יחד עם העותק. זיהוי כפילות מציע עותק נוסף או כותר אחר. בהשאלה בוחרים עותק פנוי, שם ותאריך, ומאשרים סיכום. החזרה מבקשת מיקום, שומרת היסטוריה ומציעה ביטול. אין תאריך החזרה מחייב, מספרי טלפון או הודעות חיצוניות.

## ארכיטקטורה

React / Vinext על Cloudflare Workers. אובייקט ספרייה מאומת נשמר ב-D1 עם מספר גרסה והשוואה אטומית; כל העדכון כולל כותר, עותק והשאלה נשמר כיחידה אחת. R2 שומר קבצי תמונה. דפדפן שומר רק העדפת שפה וטיוטת צילום זמנית אם ההעלאה נכשלת. רענון בין מכשירים כל 30 שניות כשאין טופס פתוח. הקוד מופרד למודל, תרגום, שירותי תמונה, API וממשק.

הממשק תומך בעברית RTL ואנגלית LTR. העיצוב שמנת, ירוק עמוק ונגיעות פליז, ניווט צד במחשב וניווט תחתון בטלפון. האתר הפרוס נשאר פרטי לבעליו באמצעות גישת Sites; אין מנגנון חשבונות נוסף באפליקציה.

## זיהוי

OCR מקומי בדפדפן באמצעות Tesseract, עברית ואנגלית. חילוץ טקסט מתמונה אינו הוכחה להתאמת ספר: כל פריט דורש אישור. חיפוש הקטלוג משתמש ב-Open Library ובכריכות שלו. ברקוד משתמש ב-BarcodeDetector כשזמין, עם חלופה של ISBN מוקלד. אין מודל ראייה שמפלח אוטומטית שדרות ומאמת את פרטי הספר; אין להציג OCR כזה כזיהוי בטוח.

## אמינות

גיבוי מלא כולל תמונות שהועלו, אימות מבנה וקשרים לפני ייבוא, אישור החלפה ואפשרות ביטול. שמירה שנכשלת משאירה טופס פתוח. עדכון על בסיס גרסה ישנה מקבל שגיאת התנגשות במקום דריסת נתונים. אין מחיקת כותר מושאל; מחיקה עם היסטוריה דורשת אישור. כותר ועותק לעולם לא נוצרים בנפרד.

3. קטלוג, צילום, ברקוד וטיוטות.

5. בדיקות, סקירה, GitHub ופריסה פרטית.
